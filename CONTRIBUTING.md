# Contributing to EGO TOOL

Thanks for wanting to help! You don't need to be a developer to contribute.

## Ways to help

| How | Where |
|---|---|
| 🐛 Report bugs | GitHub Issues → *Bug report* template |
| 💡 Suggest features | GitHub Issues → *Feature request* template |
| 🧪 Beta testing | Ask for the Beta Tester role in our community |
| 🌍 Translations | Ask for the Translator role; we use a shared translation sheet |
| ✍️ Docs & guides | Improve the FAQ or Getting Started guide |
| 🎨 Design feedback | Share screenshots and ideas in the feedback channel |
| 🤝 Help others | Answer questions in the help channel |

## Good first steps

1. Read the [Community Guidelines](docs/COMMUNITY.md).
2. Try the app for a week and note anything confusing.
3. Look for issues labelled **good first issue** or **help wanted**.

## Reporting a bug well

Include: app version, device/OS, what you expected, what happened, and steps to reproduce.
Screenshots help a lot.

## Recognition

Every contributor is credited in the release notes, and active helpers get the **Contributor**
role in our community.
