# Getting help

1. Check the [FAQ](docs/FAQ.md) — most questions are answered there.
2. Read [Getting Started](docs/GETTING-STARTED.md).
3. Ask the community (Discord help channel — link coming soon).
4. Found a bug? Open an issue with the bug report template.

Response times: community help is usually within a few hours; the core team reviews bug reports
every Tuesday and Friday.

For privacy or account deletion requests, email **support@egotool.app**.
