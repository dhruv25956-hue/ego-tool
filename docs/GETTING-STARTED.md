# Getting Started with EGO TOOL (3 minutes)

1. **Install** EGO TOOL from the [latest release](https://github.com/dhruv25956-hue/ego-tool/releases/latest).
2. **Pick 1–3 habits.** Start small. Add a *minimum version* for each (e.g. *Read → 1 page*).
3. **Set your focus length.** Default is 25 minutes focus / 5 minutes break.
4. **Do one focus session today.** Press **Start** on the home screen.
5. **Do your first Ego Check tonight.** It takes 30 seconds.
6. **Check your Weekly Mirror on Sunday.**

## Tips from the community

- Put your hardest habit first in the morning.
- Use *skip days* for rest days instead of breaking streaks.
- Join a Pod — people with a Pod keep streaks 2× longer (beta data).
- Don't add more than one new habit per week.

## Keyboard shortcuts (desktop)

| Shortcut | Action |
|---|---|
| `Ctrl/Cmd + Enter` | Start / pause focus session |
| `Ctrl/Cmd + H` | Open Habit Board |
| `Ctrl/Cmd + M` | Open Weekly Mirror |
| `Ctrl/Cmd + ,` | Settings |
